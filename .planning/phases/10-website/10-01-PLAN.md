**Update Hero.astro** (WEB-06):
- overview.json now contains `data_freshness: {tiktok: "2026-03-31", instagram: "2026-03-31"}`
- In the frontmatter script, compute staleness:
  ```js
  const freshness = (overview as any).data_freshness || {};
  const now = new Date();
  const isStale = (dateStr) => {
    if (!dateStr) return true;
    const d = new Date(dateStr);
    return (now.getTime() - d.getTime()) > 7 * 24 * 60 * 60 * 1000;
  };
  const tiktokStale = isStale(freshness.tiktok);
  const instagramStale = isStale(freshness.instagram);
  const anyStale = tiktokStale || instagramStale;
  ```
- If `anyStale` is true, render a warning badge below the hero-update paragraph:

  {anyStale && (
