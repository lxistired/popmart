**Layer 2 — Separate discovery from comment refresh (scrape_hashtag, lines 369-480):**
Replace the current flow:
- OLD: query all existing video_ids → filter to new_ids only → fetch detail + comments for new_ids only
- NEW:
  a. Query existing video_ids into `existing` set (keep this for logging)
  b. For EACH discovered video_id (not just new ones):

     - Call upsert_video_metadata() to insert-or-update (replaces batch_insert)
     - If video needs comment refresh (not in existing, OR last_comment_scraped_at IS NULL): fetch_video_comments() and save
     - After successful comment save: UPDATE tiktok_videos SET last_comment_scraped_at = current ISO timestamp WHERE video_id = ?
  c. Log clearly: "[i/total] vid_id | date | views=X | @author | NEW" or "| REFRESH" or "| meta-only"

Specifically in scrape_hashtag():
- Remove the `if not new_ids: return 0, len(video_ids)` early return
- Change the loop to iterate over ALL video_ids (not just new_ids)
- For each video: fetch_video_detail → upsert_video_metadata → decide if comments needed
- Comment decision: `needs_comments = (vid_id not in existing) or _needs_comment_refresh(conn, vid_id)`
- Helper `_needs_comment_refresh(conn, video_id)`: query last_comment_scraped_at for this video. Return True if NULL. Also return True if create_time is within 90 days AND last_comment_scraped_at is older than 7 days. Otherwise False.
- After saving comments: `conn.execute("UPDATE tiktok_videos SET last_comment_scraped_at=? WHERE video_id=?", (datetime.now(timezone.utc).isoformat(), vid_id))` then `conn.commit()`
